# WatchPilot Lab｜資料與授權政策

1. 本Fork保留Screenbox原MIT授權、作者聲明及歷史來源。新研究程式碼採MIT。
2. Fixture合成片名、期限、權益僅為程式測試使用；UI不得把其描述成Netflix／Disney+等真實OTT資訊。
3. Research Mode必須與Fixture隔離。`VERIFIED`與`OBSERVED`分開呈現；來源失敗不能表示作品下架。
4. TMDB與JustWatch衍生的觀看平台資訊必須依各自條款署名；API免費或非營利用途不等於允許轉售／再散布資料。
5. 未經合法授權，不在GitHub存放完整第三方片庫快照、作品素材或付費API回應。
6. 個人API Key僅由執行者設定於環境變數，不進入版本控制；不收集OTT登入帳號或密碼。
7. 若未來對外公開託管，需要重新審查每個API允許的商用／非商用、快取、展示及轉授權範圍。
