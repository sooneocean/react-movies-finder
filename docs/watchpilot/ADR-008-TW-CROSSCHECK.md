# ADR-008｜台灣OTT片源雙來源交叉驗證與訂閱研究門檻

日期：2026-11-08。範圍：WatchPilot Lab v0.8，非營利個人開源研究。

## 核心決策

**不把TMDB／JustWatch第三方觀測等同於OTT平台已確認可播放，也不從部分樣本推論整個平台應該退訂。**

新增`/lab/verify`：研究者從既有`/lab/tw`搜尋真實電影並加入雷達後，自行開啟相應OTT頁面檢查片名與權益，再把**自己看到的實際結果**、時間及HTTPS參考網址記錄在本機瀏覽器。

### HumanCheck V1
每筆資料包含`tmdb:<id>`、平台ID、原TMDB觀測時間、人工核對時間、人工查看的HTTPS網頁、觀測結果（訂閱／免費／含廣告／租借／購買／未找到／無法確認）、使用者主動勾選核對。

- 沒有核對，不是已確認可看。
- 手動宣稱「訂閱可看」而TMDB未列出該作品／平台／權益，產生`DISAGREEMENT`，不可直接進入研究片單。
- TMDB有權益但研究者查不到時，產生`DISAGREEMENT`，也不可排入。
- 人工核對與TMDB快照任一超過72小時，或快照已更新，標記`STALE`並禁止使用。這個72小時是**產品內部保守新鮮度政策**，不是平台授權保證。
- 無法確認標記`UNKNOWN`，不計入一致率；不能寫成未找到。
- 來源網址由使用者提供，本系統只檢查HTTPS與基本格式，**不會自動辨識它是否真為平台官方網址**。因此結果標示「使用者人工核對」而非「已由平台認證」。
- 每部電影／平台僅保留最新核對；最多200筆、僅本機localStorage，並提供刪除功能。不會在GitHub或中央API上傳完整人工紀錄。

### 最小研究門檻（非統計認證）

下列值是v0.8的**探索性、可被挑戰的政策預設**：
1. 至少20部不同電影有近期可比較資料。
2. 至少2個OTT平台，且每平台至少5個有效核對。
3. 近期結果一致率至少80%。
4. 不存在過期、失效或無法對應至目前追蹤作品的舊核對。

通過只能寫「達到初步擴大研究門檻」，**不能說已證明台灣OTT平台整庫資料準確率80%以上**，也不能直接推導訂閱應取消。未通過仍可查看單片實驗結果，但不能提供平台層級停訂判斷。

### 研究排程與訂閱邊界

只從同一部作品、同一台灣平台、同一**訂閱／免費權益**、兩來源最近72小時內相符的觀測中建立7天候選；不會用租片或含廣告項目假扮已有訂閱。後續日期仍可能變動，所有結果保留`OBSERVED`來源標記，不會提升成平台官方`VERIFIED`。

品味護照與個人已訂閱平台可參與排程；正式的30天訂閱最佳化**暫不使用未完成交叉驗證的實際片庫**。使用者輸入的費率不得被當作當下官方現價。

已修復先前`toResearchCandidate`未保留`expiryEvidence`的缺口：使用者核對過的官方期限可正確沿用於排程，但它仍獨立於可觀看性證據。

### 研究限制

此頁是Local-first人工驗證工作台，沒有權限登入OTT、掃描大量授權片庫、驗證所有平台影片或保證播放。Fixture演練與真實雷達完全隔離，不能將合成作品上線到台灣片庫。第三方TMDB、JustWatch、Netflix等平台的素材與資料仍各自受授權條款限制。

### 驗收

依`docs/watchpilot/QA-TW-CROSSCHECK.md`執行，包含API無金鑰的Fixture、Mock本機查核、20部探索性統計、Chrome瀏覽器自動測試、型別與建置，以及研究者實際逐部核對。
