# ADR-004｜LINE TV台灣官方下架公告匯入

## 2026-11-07決策
WatchPilot Lab PR #4新增官方公告Adapter，但**不建立自動網頁爬蟲**。個人使用者自行開啟LINE TV台灣官方客服公告，複製當前頁面文字，在`/lab/official/line-tv`貼入後，系統從結構化文字解析片名、類別與預定下架日期。

官方來源（台灣地區單一文件）：
https://help.linetv.tw/hc/zh-tw/articles/56415479134873-即將下架影片清單-台灣

參考的官方公告列出「影片名稱、類別、預計下架日」，並明確說明可觀看至下架日**23:59**。頁面可能不定期更改，日期與片庫仍須以使用者當下檢查為準。

## 資料流程
1. 使用者貼入當前官方表格文字。
2. Adapter僅接受上述官方台灣文章來源，拒絕非台灣頁、釣魚相似網域、不安全HTTP。
3. 支援Markdown／管線文字、Tab分隔與常見純文字格式，日期正規化為`YYYY-MM-DD`。
4. 去除完全重複資料，非法日期拒絕，同片名多個不同日期列為衝突，不自動處理。
5. 跟使用者在`/lab/radar`追蹤的TMDB作品比對，**只有正規化標題相同且唯一時提出建議**；同名、多譯名、不相符均需研究者本人核對。
6. 由使用者逐筆確認片名、TMDB作品ID、官方日期與來源，再將「USER_REVIEWED_OFFICIAL」期限寫入本機雷達。
7. 下架日期不提升TMDB／JustWatch的`OBSERVED`可用性證據等級。若TMDB沒有提供LINE TV片源，該期限仍可保存，但**不會產生虛構可觀看權益**。
8. 若同作品仍有其他合法訂閱平台，不能直接說「這部電影全台灣即將下架」。

## 非目標
- 不在程式碼內保存官方完整清單或第三方片庫轉儲。
- 不宣稱官方網站自動核驗、即時同步、背景更新。
- 不提供未經核准的整站爬蟲、API鏡像或多平台內容批次收集。
- 不將同名作品自動視為同一部作品。
- 不把已過去日期當成目前下架提醒。

## 隱私與使用限制
- 原始公告文字只在瀏覽器本機解析，預設不儲存到後端或GitHub。
- 僅保留逐筆人工核對的必要欄位（作品ID、LINE TV平台ID、日期、公告HTTPS網址、查核時間）。
- 原始出版者對公告文字的權利與網站使用條款仍適用；採用MIT授權的是本專案程式碼，不是第三方公告內容。
- 此流程專供個人非營利科學研究，對外公開自動化服務前須重新驗證授權與最新官方來源。

## 後續可擴展
建立其他官方平台的來源Adapter，但每個Adapter必須有正式的來源識別、地區限定、查核規則、授權檢查和誤報測試。若能合法取得結構化官方API，可另行實作按需擷取，而不要求使用者貼入文字。
