# WatchPilot Lab｜PR #2台灣片源研究驗收

## 範圍與限制
本PR提供TMDB台灣電影資料查詢與對應的JustWatch觀看平台**觀測**資料，沒有官方授權到期日期，也沒有實測Netflix、Disney+等OTT帳戶可否播放。資料取樣不能證明涵蓋所有台灣平台或全部作品。

## 本機設定
1. 安裝Node.js 22及npm。
2. `npm ci`
3. 在專案根目錄建立`.env.local`，填入`MOVIE_DB_API_KEY=你的TMDB_v3_API_Key`。
4. `npm run test:watchpilot`和`npm run type-check`。
5. `npm run dev`後開啟`http://localhost:3000/lab/tw`。
6. 不填Key仍可使用`http://localhost:3000/lab`進行合成Fixture研究。

## 必須人工驗收的情境
- [ ] 中文片名搜尋：能取得不超過5部候選、繁體中文標題與可用片長。
- [ ] 在API Key未設定時顯示明確訊息，且不影響Fixture模式。
- [ ] 僅顯示TMDB回傳的TW平台；沒有TW結果時**不回退使用US結果**。
- [ ] 訂閱／免費／廣告／租借／購買分開呈現；僅訂閱與明確免費可直接計畫。
- [ ] 取消所有訂閱後，不推薦僅有訂閱、租片或購買權益的作品。
- [ ] 不知道片長的電影不可被排程。
- [ ] 每日及每週觀看時間不得超標。
- [ ] 觀測資料超過7天、安排日期早於觀測日都不視為當天可看。
- [ ] 無論資料結果如何，都不顯示虛構官方下架倒數。
- [ ] 每部實際影片有資料來源、TMDB觀看頁連結（如提供）及查詢時間。
- [ ] API服務異常時提供錯誤，**不能**顯示作品已下架。
- [ ] 頁面可見TMDB及JustWatch署名與TMDB標誌。
- [ ] 從`/lab`能進入`/lab/tw`，不影響上游電影搜尋與片單。

**未做完人工交叉驗證前，不得宣稱台灣片庫覆蓋率或準確率。**

## 安全與資料政策
- 不公開TMDB API Key。
- 不以整庫爬取或再散布第三方片源資料。
- 本API搜尋最多5部候選，避免不必要的批次請求。
- 本機試驗服務預設只供個人使用；對外託管前需再處理存取控制、速率限制、授權及快取政策。
- TMDB要求標誌與指定英文聲明；JustWatch提供觀看平台資料，須署名。
