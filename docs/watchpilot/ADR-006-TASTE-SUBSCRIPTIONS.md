# ADR-006｜Taste Passport與30天OTT訂閱策略研究

日期：2026-11-07｜階段：WatchPilot Lab v0.6（個人非營利研究版）

## 核心決策
在既有Screenbox＋WatchPilot實驗環境之上，新增`/lab/strategy`，以**單一使用者、本機資料、合成電影片庫**驗證「個人口味＋觀看時間＋可續費權益」的組合最佳化。

### 1.個人品味護照
- 類型可以明確標記「喜歡／避開／無偏好」，避開為排程硬限制，喜歡為加分。
- 研究者可對合成電影給出非常喜歡、喜歡、普通、不喜歡及已看標記。
- 演算法在原始tasteScore上做有界、可解釋加減分；不宣稱模型已經理解個人心理或實際電影口碑。
- `TastePassport v1`與最多100筆意見存於同一台瀏覽器的localStorage，可清除、不上傳AI服務。
- 品味護照可用於`/lab`、`/lab/tw`、`/lab/radar`與`/lab/strategy`排程，但不會自動傳給Jev。

### 2.30天訂閱成本模擬
- 模擬對象：1至6個OTT平台（目前介面提供Netflix、Disney+、HBO Max、Prime Video）。
- 使用者填入每個平台的**真實續費金額、月繳／年繳、目前是否訂閱、已預付可觀看至哪一天（含當日）及下次續費是否可避免**。
- 所有預設價格只是合成Fixture，不代表2026年任何平台官方售價；想使用真實價格必須切換模式並勾選人工確認。
- **沉沒成本不當成可省費用。**若已付費期間覆蓋30天，即使模擬停訂也保留期間內的可觀看權益，而且新增續費費用為0。
- 假設每個月／年購買的是整期費用，不計中途退款、優惠、家庭方案、匯率、稅項或退款限制；均由使用者自行確認。
- 30天視窗內依實際預付截止日與模擬續費事件建立**日期限定的可觀看權益**，不可把訂閱到期偽裝成電影版權下架。
- 枚舉所有平台保留／購買子集合（最多64種），在每個組合中以Greedy基準安排合成片單，再比較成本與觀看價值。子集合列舉是完整的，但片單本身**不保證全域最優**。

### 3.對照情境
1. 維持目前訂閱：對既有訂閱視為持續續費，未訂閱平台不自動新購。
2. 停止可取消續費：只保留不能在到期時避免的新費用；仍可使用先前已付款的期間。
3. 平衡方案：最大化「觀看效用−費用懲罰」，懲罰權重由使用者設定，並非普遍財務標準。
4. 最大觀看價值：優先最大化排入作品的效用，再比較費用與複雜度。

差額以**模擬期間可能新增的付款之間的差異**表示，不標示已節省現金，不提出確定應該取消訂閱的指令。

### 4.開源與資料政策
- 不讀取／修改OTT帳號，不請求登入密碼，不下訂或取消訂閱。
- 訂閱費、觀影偏好及已看紀錄只存本機瀏覽器。唯一對外資料仍是既有、由研究者自行啟用的第三方API。
- 預設合成片庫與合成費率；即使使用者輸入真實費率，**片庫仍然是合成的**，不可當作真實商業、法律或財務建議。
- GitHub只發佈程式碼與合成Fixture，不上傳個人價格、片單或未取得授權的第三方資料。

### 5.後續拓展的驗收門檻
- 研究者完成真實片庫20部作品抽樣後，才考慮把本功能的電影候選改用合法台灣OTT來源。
- 必須另行處理平台實際帳單、付款週期、價格變更、家庭／廣告方案、優惠與到期時間的差異。
- 對比Greedy與精確求解器，不能因為「完整列舉平台子集合」就宣稱整體觀影計畫數學最優。
