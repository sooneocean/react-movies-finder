# WatchPilot Lab｜PR #4 LINE TV官方下架公告驗收

## 本機啟動
```bash
git fetch origin
git checkout feat/watchpilot-line-tv-official
npm ci
npm run test:watchpilot
npm run type-check
npm run lint
npm run dev
```

- 無金鑰可進入`/lab/official/line-tv`查看匯入介面與解析合成格式。
- 若要實測真實TMDB作品配對，先在本機`.env.local`設定個人`MOVIE_DB_API_KEY`，用`/lab/tw`搜尋並「加入雷達」。
- 從`/lab/radar`的「人工查核官方下架公告」區塊進入匯入器。

## 合成格式測試（禁止當真實公告儲存）
```text
類別 | 影片名稱 | 預計下架日
電影 | 虛構實驗電影甲 | 2026-11-25
電影VIP | 虛構實驗電影乙 | 2026/11/30
```

測試中的片名及下架日期完全合成，**不代表任何LINE TV實際片庫**。

## 驗收清單
- [ ] 來源URL只接受LINE TV台灣官方指定文章，拒絕其他國家文章或相似網域。
- [ ] 可解析`2026/11/30`與`2026-11-30`，顯示一致的日期格式。
- [ ] 表格欄位「類別｜片名｜日期」或「類別｜日期｜片名」都能正確處理。
- [ ] 日期不合法、同片名不同下架日期必須明確阻止或要求查證。
- [ ] 解析成功不等於自動儲存；必須選擇TMDB追蹤作品並親自勾選核對。
- [ ] 名稱相同只提出配對建議，不自動核准；名稱不同需額外核對身份。
- [ ] 預定下架日視為台灣日曆日，最後觀看時間依來源說明為23:59；過期日期不出現在即將下架預設清單。
- [ ] 只保存使用者核准的必要欄位，原始貼上的完整公告不進GitHub或本機工作區永久紀錄。
- [ ] 沒有LINE TV觀測片源時，記錄期限但不自行創造LINE TV訂閱觀看權益。
- [ ] 已保存的期限可在`/lab/radar`顯示；若已有對應LINE TV片源，重新排程時能限制到期後的時段。
- [ ] 舊PR #1至#3的離線Fixture、TMDB查詢、雷達合成演練仍可運行。
- [ ] 實測當前官方頁面內容是否變更（日期、影片欄位、公告格式）；若格式變更，先修Parser再啟用相應流程。

## CI與人工驗收狀態
GitHub Actions尚無成功執行證據前，這些核對項目均維持未通過；人工驗收需由研究者實際操作。此PR不得直接合併`master`。
